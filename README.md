## Projects

**AutoDeploy AI - Intelligent CI/CD Pipeline with Self-Healing Infrastructure**
End-to-end CI/CD pipeline where a GitHub push triggers CodePipeline to build a Docker image, push it
to Amazon ECR, and deploy on ECS Fargate. Provisioned with modular Terraform, including blue/green
deployment with automatic rollback and AI-generated incident summaries using Amazon Bedrock and
Lambda, with Prometheus and Grafana for live pipeline health.
*Tech: Terraform, Docker, AWS CodePipeline, ECR, ECS Fargate, Lambda, Amazon Bedrock, Prometheus, Grafana*

**ReadHive - Digital Library & E-Reading SaaS Platform**
Full-stack platform with admin and reader portals supporting rentals, purchases, subscriptions, and
payments. REST APIs secured with Spring Security, BCrypt, and JJWT, with a Python ML microservice for
recommendations and analytics.
*Tech: Java 17, Spring Boot, PostgreSQL, React, Python (FastAPI), JWT*

**Stash-Img - Self-Hosted Image Library**
Self-hosted image library served from a single containerised port, with background job queues,
filesystem watchers, and an opt-in semantic search using local CLIP embeddings that keeps all data
on-device.
*Tech: Go, Gin, GORM, PostgreSQL, React, Vite PWA, CLIP*
